# 過去問クイズシステム 運用マニュアル

Quarto (GitHub Pages) 上で、Google スプレッドシートの過去問データを動的に読み込んで表示するシステムです。

## 🏗️ 開発者向けガイド (Developer Guide)

システム全体の構造、コードの保守、GASおよび全体マスターでのID紐づけ手順です。

### 1. 全体構造・データフロー

* **【受験者 / Webブラウザ】**
  * Quarto Webサイト (`.qmd`) から `schoolName`, `kakomonName`, `passcode` を送信
* **【GAS (ウェブアプリ)】** （実行権限: システム開発者 Baba）
  1. 『全体マスター』を開き、指定された `Kakomon_name` から「学校マスターID」を取得
  2. マッチした『学校マスター』を開き、Passcode検証・問題データ・カテゴリ設定を取得してブラウザへ返却

### 2. 重要IDおよび設定の保管場所

* **全体マスター ID (`MASTER_ADMIN_ID`)**
  * `Code.gs`（GAS側）の冒頭に定数として設定します。
  * ID: `1tm6YBQ52wCqMjM4HSrpo1pp1gwNd9YpF-liLb-Cvqec`
* **GAS ウェブアプリ エンドポイント URL**
  * `load_gsheet.js` の `gasUrl` 変数に設定します。
  * URL: `https://script.google.com/macros/s/AKfycbyfb8SbR4xyO9ygmKFrMHiqwexntoxXWf_hUfJwUIq-ywwqjr2dQtL8Qv6vVT8nuNg/exec`

### 3. 【開発者作業】新しい過去問の登録・公開手順

先生から新しい「学校マスター（スプレッドシート）」の連絡を受けた際の手順です。

1. **アクセス権の確保:** 先生から学校マスターの**閲覧権限**（Baba宛）が付与されていることを確認します。
2. **IDの取得:** 学校マスターの URL から「スプレッドシートID」を取得します。
   * URL例: `https://docs.google.com/spreadsheets/d/`**`1tm6YBQ...`**`/edit` の太字部分
3. **全体マスターへの登録:**  
   『全体マスター』スプレッドシートを開き、`admnin` シートに新しい行を追加して `Kakomon_ID` に上記IDを登録・紐づけます。
4. **.qmd ページの作成:**  
   リポジトリ内に `.qmd` ファイル（例: `test_kokoro.qmd`）を作成し、先生が指定した `Kakomon_name` をセットしてビルド・Pushします。

## 🏫 学校の先生・管理者向けガイド (Admin Guide)

問題データの作成、合言葉（Passcode）の設定、出題カテゴリの変更手順です。先生はご自身の**「学校マスター」スプレッドシートのみ**を管理します。

### 1. 学校マスター（スプレッドシート）の構成と役割

先生が管理する「学校マスター」ブック内には、以下のシート（タブ）を用意します。

#### ① `admnin` シート（全体設定用）
1行目にヘッダー、2行目に各設定を入力します。

| School_name | Kakomon_name | Passcode | Kakomon_sheet | Category_sheet |
| :--- | :--- | :--- | :--- | :--- |
| *(空欄可)* | **第38回こころとからだのしくみ** | **nuhw2026** | Kakomon | Cat_kokoro |

* **`Kakomon_name`**: 科目の識別名です（開発者に伝える名称）。
* **`Passcode`**: **テストの合言葉**です。先生の好きなタイミングで自由に書き換えて変更できます（不要なら空欄）。
* **`Kakomon_sheet`**: 問題データが入っているシート名。
* **`Category_sheet`**: 表示・出題制限を行うカテゴリ設定シート名。

#### ② `Kakomon` シート（問題データ）
問題文、選択肢、正解、解説などを入力するシートです。

#### ③ `Cat_xxx` シート（カテゴリ出題設定）
ページに表示・出題するカテゴリとその出題数をコントロールするシートです。

| category | count |
| :--- | :--- |
| 身体の構造 | 10 |
| メンタルヘルス | 5 |

## ❓ トラブルシューティング（先生向け）

* **「合言葉（Passcode）を変更・削除したい」**
  * 学校マスター内の `admnin` シートにある `Passcode` 列の文字を直接書き換えるだけで、即座にWeb側にも反映されます。
* **「出題するカテゴリや問題数を調整したい」**
  * 学校マスター内の `Category_sheet`（例: `Cat_kokoro`）に記載されている数値（`count`）を変更するだけで調整できます。
* **「問題が読み込まれない」**
  * 開発者（Baba）へ「学校マスター」の閲覧権限が付与されているか、および全体の紐づけ作業が完了しているか確認してください。
